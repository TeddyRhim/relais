# Sécurité

Relais est un projet de démonstration : le faux fournisseur de facturation n'encaisse rien et ne doit pas être utilisé tel quel pour de vrais paiements.

Pour signaler une vulnérabilité, ouvrez un signalement privé depuis l'onglet « Security » du dépôt (Report a vulnerability) plutôt qu'une issue publique. Merci d'indiquer la version, les étapes pour reproduire et l'impact estimé.

Aucun secret n'est versionné : les clés, mots de passe et jetons viennent de l'environnement (voir `.env.example`).
